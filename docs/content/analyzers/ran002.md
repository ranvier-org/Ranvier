`warning RAN002`: *`policy.IsQueue` calls a compiler-generated union tester, which a Fable precompiled assembly does
not declare.*

**Cause.** F# generates an `IsCase` property for each union case. A Fable precompile of the library that calls one fails
with `MethodDefNotFound` for the getter, for public, internal and private unions alike (Fable 5.18.0). The Fickl 0.3.0
precompile, the repository's compiler since #152, declares the testers; the rule keeps a library precompilable by Fable
5.18. The rule reports every tester of a union declared in the project, generic unions included.

**Fix.** Match on the case. The rule's fix writes the `match`.

### Triggers

```fsharp
module Example

type Policy =
    | Queue
    | Drop of int

let queued (policy: Policy) = policy.IsQueue
```

### Fixed

```fsharp
module Example

type Policy =
    | Queue
    | Drop of int

let queued (policy: Policy) =
    match policy with
    | Queue -> true
    | _ -> false
```

**Suppression.** `// fsharpanalyzer: ignore-line RAN002`, with the reason on the line before.
